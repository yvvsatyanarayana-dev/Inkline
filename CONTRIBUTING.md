# Contributing to Inkline

This repository is dedicated to project documentation, issue tracking, and installer releases. The core source code of the application is maintained in a separate, private repository.

## How to Contribute

### 1. Reporting Bugs & Suggesting Features
* Use the **Issues** tab to report bugs in the release binaries or to suggest feature enhancements.
* Please use the provided Issue templates when submitting a bug report.

### 2. Documentation Updates
* If you see typos, incorrect installation steps, or missing details in the README or other documentation files in this repository, you are welcome to submit a Pull Request.

### 3. Source Code Contributions
* If you are a member of the team and want to make changes to the application code, please switch to the **private source code repository**. 
* If you do not have access to the source code repository, please contact me.
