# Security Policy

## Supported Versions

Only installer releases published in this repository are actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Because the core source code of Inkline is private, please **do not** open public GitHub issues for security vulnerabilities.

If you discover a security vulnerability in the release builds:
1. Send a private message or email directly to me.
2. Provide details on how to reproduce the issue.
3. We will fix the issue in the private source code repository and publish a new installer release here as soon as possible.
