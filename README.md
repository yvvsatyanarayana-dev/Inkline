# Inkline
Inkline is a polished, cross‑platform Electron desktop app for sketching, diagramming and exporting visuals. It provides shapes, freehand tools, layers, save/load (JSON), and PNG export. This repository contains product documentation and downloadable installers (Windows, Linux, macOS); source code is not published here

## Features
- **Canvas & Input**
  - A responsive, zoomable canvas with grid and minimap for easier layout and navigation.
  - Hand (pan) and Select tools for moving around and manipulating elements.

- **Shape Tools**
  - Rectangle, Diamond, Ellipse: draw and style basic shapes with stroke, fill, corner style (rounded/sharp) and opacity.
  - Frame: dashed frames for grouping or visually separating areas.

- **Lines & Connectors**
  - Line and Arrow: straight connectors with snapping to element ports for quick flowchart/diagram construction.
  - Flowchart ports (N/S/E/W) enable binding connectors to shapes so connections stay attached when elements move.

- **Freehand & Smart Pen**
  - Pen tool with calligraphic stroke rendering that responsively varies thickness for an organic look.
  - Smart pen shape recognizer converts rough freehand shapes into clean primitives (line, arrow, rect, diamond, ellipse) when detected.

- **Text**
  - Multi-line text blocks with selectable font families and sizes, editable in-place, and styling options.

- **Images & Embeds**
  - Insert images from local files; placed and scaled on the canvas.
  - Web embed cards with preview text and an “open link” affordance.

- **Charts & Templates**
  - Built-in sketchy chart generator (bar, line, pie) that produces editable chart elements.
  - Canvas templates: SWOT, Kanban, Mindmap, Flowchart to bootstrap common layouts.

- **Layers & Organization**
  - Multiple layers with visibility toggle, locking, ordering, and per-layer dimming for focus.
  - Group/ungroup, duplicate, and z-order controls to organize complex diagrams.

- **Alignment & Distribution**
  - Align left/center/right/top/middle/bottom and distribute horizontally/vertically for fast layout adjustments.

- **Interaction & UX**
  - Rulers, snapping guides, alignment guides, resize handles and selection highlights for precise editing.
  - Lasso selection and a laser-pointer mode for presentations or collaborative screen-sharing.

- **Annotations & Attachments**
  - Attach link URLs to elements and an audio memo recorder/player attached to individual elements.

- **Persistence & Export**
  - Save/load boards as JSON (portable project files).
  - Export the canvas to PNG for sharing or presentation.

- **Usability**
  - Templates, a properties panel that adapts to selection/tool context, keyboard shortcuts, and a minimal, polished UI.
